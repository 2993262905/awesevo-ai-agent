# AwesEvo

一个本地运行的 Agent 桌面工具。自己接 API、提示词模板化、工具可开关、权限可分档。

## 启动

双击 `启动.bat`，浏览器会自动打开 `http://127.0.0.1:4173`。

或者命令行：

```bash
node server/index.js
```

需要 Node.js 20+，没有任何第三方依赖。

## 第一次使用

打开后会先让你定 **AI 的活动范围**，二选一：

| 模式        | 能碰什么                     |
| --------- | ------------------------ |
| **专用工作区** | 只在一个文件夹里读写，其他位置一律拒绝      |
| **全权接管**  | 整个用户目录都能读写；系统目录、密钥目录永久拒绝 |

选专用工作区时，会自动探测**空闲最多的非 C 盘**并建议放那里（比如 `D:\awes-workspace`），不想用可以自己改路径；只有 C 盘时才会退回用户目录。

随时可以在「设置 → 通用 → AI 活动范围」里重选。

**开箱就能聊。** 内置了「免费体验通道」（公共网关，无需 Key），打开页面直接发消息即可。

两个限制要说清楚：**每 IP 每 30 秒只能请求 1 次**，而且**只支持纯对话、不能调用工具**——这个通道的模型工具调用输出不稳定，会生成畸形参数。所以想让它真的改代码，得配自己的 Key。

1. 点左下角 **设置**（或右上角齿轮）→ **模型与 API**
2. 选一个服务商填 API Key，或点 **+ 添加服务商** 填自己的端点
3. 点 **测试** 验证连通，成功可以一键导入该端点下所有模型
4. 顶部模型下拉切过去，就用自己的通道了

模型下拉里每个服务商下面都有一项 **「⟳ 获取可用模型」**，点一下会实时向服务商要一份模型列表（`GET /v1/models`），选中就直接切换过去；没加过的模型会自动补进列表。

不支持 `GET /models` 的端点（比如 Anthropic 原生接口）会明确告诉你，改成手动添加即可。

**工作区**默认由首次引导决定（一般放在空闲最多的非 C 盘）。做别的项目时，在左侧「文件」页把路径换成你的项目目录，或者点「切回工作区」——如果你当前停在 C 盘，它会自动跳到空闲最多的盘。

想让 Agent 改 AwesEvo 自己？**直接说就行，不用切工作区。** 工作区在别的盘时，它写 `web/css/...`、`web/js/...`、`server/...` 这些路径会自动定位到应用目录；CSS 改完会实时热替换。

装了 Ollama 的话不用管，启动时会自动探测并接进模型列表。

支持的接口格式：

| 格式        | 适用                                              |
| --------- | ----------------------------------------------- |
| OpenAI 兼容 | DeepSeek、Kimi、Qwen、硅基流动、Ollama、vLLM、OneAPI、各类中转 |
| Anthropic | Claude 原生 Messages API                          |

API Key 只存在本机 `data/config.json`，不经过任何第三方。

## 改代码立刻生效

AwesEvo 会实时监听 `web/` 目录：

- **改 CSS** → 页面自动热替换样式表，**不刷新、不丢状态**，颜色和间距当场就变
- **改 HTML / JS** → 右下角弹出「刷新查看」，点一下生效（不会突然打断你正在进行的对话）

所以你可以直接对它说「把背景改成蓝色」，它去改 `web/css/app.css`，你眼前的页面马上就变色。

## 消息与会话操作

| 想做什么                 | 怎么做                           |
| -------------------- | ----------------------------- |
| 重新生成这一轮              | 鼠标移到助手回复上 → **重试**            |
| 删掉这一轮                | 移到助手回复上 → **删除**（连同你那条提问一起删）  |
| 改一下提问再发              | 移到你的消息上 → **编辑**（放回输入框，删掉这一轮） |
| 重命名 / 导出 / 清空 / 删除会话 | 在左侧会话上**右键**                  |
| 改文件后看新结构             | 文件树会自动刷新                      |
| 翻得太往上                | 右下角 **回到最新**                  |
| 全部关闭工具               | 检查器 → 工具 → **全关**             |

## 核心概念

**提示词模板**　右上角的模板按钮一键切换。每个模板支持 `{{变量}}`：  
`{{workspace}}` `{{date}}` `{{time}}` `{{os}}` `{{model}}` `{{provider}}`，以及模板自定义的变量。  
右侧检查器里可以直接改 system prompt、改变量值、预览渲染结果。改内置模板不丢，随时可「恢复默认」。

**工具**　Agent 有 12 个工具：读文件、写文件、精确替换、移动/重命名、复制、删除（走回收站）、查看文件信息、列目录、按名找文件、按内容搜索、执行命令、维护待办。  
在检查器「工具」页可以逐个关掉——关掉的工具不会出现在请求里，模型也不知道它存在。

**权限模式**　顶栏三档：

- 只读：只能看，不能改
- 确认：每次写文件/跑命令前问你
- 自动：直接执行（高风险命令仍会拦）

**工作区**　所有文件操作被限制在这个目录内，路径穿越会被拒绝。

## 目录

```
server/
  index.js            HTTP 服务 + API 路由 + SSE
  lib/agent.js        Agent 循环（多轮工具调用、防死循环、权限确认）
  lib/store.js        配置 / 会话 / 提示词持久化 + 变量渲染
  lib/prompts.js      内置提示词模板
  lib/llm/            模型适配层（openai / anthropic）
  lib/tools/          工具实现
web/                  前端（原生 ES modules，无构建）
data/
  config.json         配置（含 API Key）
  sessions/           会话记录，一个会话一个 JSON
```
